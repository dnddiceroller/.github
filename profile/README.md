# D&D Dice Roller

Engineering notes, public tools and technical documentation from the team behind **[dnddiceroller.com](https://dnddiceroller.com)**.

The production platform is privately maintained. Selected components, specifications, experiments and developer resources are published here where they help the tabletop and software communities.

### What we work on

- Verifiable digital dice rolling
- Cryptographically secure randomness
- Dice probability and simulation
- Reproducible roll verification
- RNG testing and benchmarking
- Developer tools for tabletop games

A dice roller should be fast enough for a game table, and rigorous enough that anyone curious can see what happened.

**Roll dice. Keep the receipt.**
